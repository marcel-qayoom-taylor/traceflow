# Contributing

Thank you for improving Traceflow.

## Development

Traceflow requires Node.js 22 or newer and `lsof` on the host.

```bash
npm test
npm run demo
```

Keep changes focused, add behaviour-level tests for user-visible changes, and
avoid committing captured traces, credentials, or machine-specific config.

## Pull requests

- Explain the problem and the resulting behaviour.
- Include validation steps.
- Call out security or compatibility implications.
- Update documentation when configuration or commands change.
